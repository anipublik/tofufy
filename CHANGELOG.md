# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres
to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `tofufy rules` command — lists every conversion rule with its category and
  a one-line description. Supports `--category breaking|important|advisory`.
- `tofufy convert --yes` — skip the no-backup write-confirmation prompt, for
  CI / scripted use.
- `tofufy convert --output json` — machine-readable summary with per-file
  rule hits and breaking/important/advisory counts.
- `tofufy version` now reports availability of each optional integration
  (`ai`, `git`, `s3`, `gcs`) and lists supported LLM providers.
- `py.typed` marker so downstream projects pick up type information.
- Optional-dependency extras: `[ai]`, `[git]`, `[s3]`, `[gcs]`, `[all]`.
  The core install is now much leaner — `litellm`, `PyGithub`, `gitpython`
  and cloud SDKs are no longer pulled in by default.
- Pre-commit config (`.pre-commit-config.yaml`).
- macOS and Windows CI runners.

### Changed
- **BREAKING CLI FIX:** `tofufy convert <source>` is now registered as a plain
  command instead of a `Typer` sub-app, which makes its required `SOURCE`
  argument actually parse. Previously it errored with "Missing argument
  SOURCE" because Click was treating it as a subcommand group.
- File writes are now atomic (write to a sibling `.tofufy-tmp` file then
  rename). A crash mid-run no longer leaves half-written `.tf` files.
- `CloudBlockRule` now rewrites every `cloud {}` block in a file instead of
  only the first.
- PR body generated by `tofufy pr create` now groups changes by category,
  includes counts, and embeds the tofufy version.
- `StateMigrator` S3 / GCS uploads run on a worker thread via
  `asyncio.to_thread` instead of blocking the event loop.
- Coverage floor raised from 0% to 60%.
- Expanded ruff rule set: `C4`, `PTH`, `RUF`, `PIE`, `RET`, `PT`, `ARG`.

### Fixed
- Config loading (`--config`) now works: `pyyaml` is an explicit dependency
  instead of being implicitly required.
- Removed committed `coverage.xml` artifact from version control.
- Removed unused `_PROVIDER_BLOCK_RE` in `provider_version.py`.
- `tofufy version` no longer crashes when probing `google.cloud.storage`
  while the `google` namespace package is missing.
